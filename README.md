# CSE 325 Group Project

## Team Members

- Tomas Fontes

## Project Overview

This repository contains the group project for CSE 325 - .NET Software Development.

The team will design, develop, test, and deploy a .NET Blazor web application.

## Technology

- C#
- .NET
- Blazor
- Git / GitHub
- Trello

## Project Requirements

The final application will:

- Be developed as a .NET Blazor web application.
- Serve a clearly defined target audience.
- Include user authentication.
- Include CRUD functionality.
- Follow responsive design and usability principles.
- Consider accessibility and performance.
- Be tested for quality assurance.
- Include code comments and basic user documentation.
- Be deployed to a cloud service.

## Current Status

Current work includes:

- Initial Blazor application created.
- GitHub repository created.
- Project management board created in Trello.
- Team members cloning and testing the repository.
- Brainstorming possible application ideas.
